# VroumVroum_sim

Webapp de sound design de bruit moteur (moto, voiture, camion) : paramètres animés sur une timeline calée sur une vidéo, export WAV 48 kHz pour le montage.

- Cibles : Windows 11 (Chrome / Edge), iPad / iPhone (Safari). Version app Windows (PWA puis Tauri) plus tard.
